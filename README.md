# SMH + NVDA Price-Level Trade Timing App

This version analyzes current price level before recommending trades.

It classifies SMH/NVDA as:
- High price level
- Near high
- Normal pullback
- Good pullback
- Deep pullback
- Weak / below trend

Then it recommends:
- Buy now amount and shares
- Wait / no chase
- Add on pullback
- Trim or sell shares
- Stop-loss reference

Deploy on Streamlit Cloud with main file:

`smh_nvda_trade_timing_app.py`
